# startrip · MVP 프로토타입

미루던 일을 한 걸음씩 쪼개서, 픽셀 친구와 함께 숨겨진 나라로 걸어가는 목표 쪼개기 서비스 **startrip**의 클릭 프로토타입이에요.

- 화면 하나짜리 웹 페이지(`index.html`)에 모든 화면 · 흐름 · 이미지가 들어 있어요. 빌드 과정 없이 브라우저로 바로 열려요.
- 위쪽 탭에서 **직접 눌러보기 · 무료 / 직접 눌러보기 · 프리미엄 / 펼쳐보기(시나리오별 화면 나열)** 를 고를 수 있어요.

## 보는 방법

1. **내 컴퓨터에서**: `index.html`을 더블클릭해서 Chrome · Safari로 열기
2. **링크로 공유 (GitHub Pages)**: 저장소 Settings → Pages → Branch `main` / `/ (root)` → Save
   - 1~2분 뒤 `https://parksol9oo.github.io/startrip/` 에서 열려요.
   - 비공개 저장소는 GitHub 유료 플랜에서만 Pages를 쓸 수 있어요.

## 함께 수정하는 방법

1. `main`에서 작업용 브랜치를 만들어요. 예) `feat/home-empty`, `fix/s9-mic`
2. `index.html`을 고치고, 브라우저로 열어서 확인해요.
3. 커밋 메시지에 **화면 코드**를 적어요. 예) `S1 홈: 진행 목표 0개 안내 추가`
4. Pull Request를 열고, 바뀐 화면 스크린샷을 붙여서 리뷰를 받아요.
5. 승인되면 `main`에 합쳐요. Pages 링크는 자동으로 새 버전이 돼요.

> 파일이 하나라서 두 사람이 같은 화면을 동시에 고치면 충돌이 나기 쉬워요. 작업 전에 이슈나 채팅으로 **어떤 화면(코드)을 고치는지** 먼저 말해 주세요.

### 파일 안 구조 (찾아갈 때)

| 찾는 것 | 검색어 |
|---|---|
| 화면 코드 · 이름 | `CODE` |
| 펼쳐보기 시나리오 | `const PATHS` |
| 홈 화면 | `if(v==="home")` |
| 무료 / 프리미엄 규칙 | `무료 · 프리미엄 이용자 구분` |
| 로그인 · 회원가입 | `인트로 · 로그인 · 계정` |
| 마이 탭 | `마이 탭 MVP 화면` |
| 버튼 동작 | `d.a===` (예: `d.a==="new"`) |

이미지(캐릭터 · 배경 · 아이템)는 파일 안에 데이터로 들어 있어서 따로 관리할 파일이 없어요.

## 무료 · 프리미엄 규칙 (현재 프로토타입 기준)

| | 무료 | 프리미엄 |
|---|---|---|
| 동시에 진행하는 목표 | 3개 | 제한 없음 |
| 지난 기록 | 최근 도착 3개까지 열람 | 전체 |
| 광고 배너 | 있음 | 없음 |
| 쪼개기 크기 '치밀하게' | 잠김 (안내 시트) | 사용 가능 |
